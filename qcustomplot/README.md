# QCustomPlot Library

## Required Files

This directory should contain the QCustomPlot library files:
- `qcustomplot.h` - Header file
- `qcustomplot.cpp` - Implementation file

## How to Obtain

Download QCustomPlot from: https://www.qcustomplot.com/

Version 2.1.0 or higher is recommended.

Extract `qcustomplot.h` and `qcustomplot.cpp` from the downloaded archive and place them in this directory.
